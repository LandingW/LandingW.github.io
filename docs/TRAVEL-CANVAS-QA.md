# 旅行页与主页的视觉统一

验证日期：2026-10-12。本轮承接 `FULL-WIDTH-HOMEPAGE-QA.md`，将公开旅行总览与旅行详情扩展为同一套宽幅画布。

## 改动范围

- 复用主页的留白、纸色阅读层、青绿与赭色分形及滚动视差，不在旅行页重复首页的文字启动效果。
- 世界地图取消侧栏与最大宽度，统计信息横向排列；地图使用不透明纸色底，避免背景纹理与地理线条重叠。
- 旅行卡片使用双列错落的照片拼贴，手机改为单列。详情标题、国家轮廓、点位地图、影像与拍摄档案统一间距和底色。
- 公开影集主封面在桌面加载已有 2560px 预览，手机和拼贴细图继续加载缩略图。该行为由 `largePreview` 显式启用，不扩大管理页图片请求。
- 高清查看器通过 portal 放在 body 下；打开时隐藏并暂停分形，关闭后恢复。
- 没有照片的旅行详情保持一列，避免留出不存在的封面栏。
- 新样式限定在 `.travel-page`，未修改管理页、上传服务、照片/GPS/EXIF、旅行内容或四项菜单目的地。
