# UI 与动效增强 · 2026-10-12

## 设计与范围

参考 [Linear](https://linear.app/) 的导航状态反馈、薄边界和层级关系，延续本站已有的纸色 / 墨色 / 朱红。没有复制外站素材或代码，也未加入第三方动效库。保留菜单第四项旅行、首页第四区块、免费地图、Sommarøy 定位和原有茶壶 / 分形。

- 导航指示底色随悬停、焦点与章节变化平移；手机菜单展开 / 收起有层级动画，关闭时使用 inert 与 visibility 阻止误聚焦。
- 滚动入场为 620ms，组内错落最多 220ms；已在首屏的节点不额外闪入，不干扰初始标题动画。键盘聚焦会立即完成对应入场。
- 阅读进度线与鼠标视差使用被事件唤醒、合并到单帧的 requestAnimationFrame，不启用常驻循环。照片偏移限制在 ±4px，只对精细指针启用。
- 原生 View Transitions 以唯一旅行 ID 对应卡片首图和手记封面。完整预览图加载前保留卡片缩略图；不支持该 API 的浏览器继续使用正常导航。
- 文章筛选、搜索与重置在布局变化后保持筛选栏的位置。直达首页内容锚点跳过开场降噪。
- 无 JavaScript 时正文默认可见；减少动态效果、静态模式、打印和后台状态有降级处理。清理观察器、事件监听与已创建动画。

## 已验证

- 57 项自动化测试通过，含原有 53 项回归；lint、TypeScript 和 Next.js 静态生产构建通过。
- 浏览器从首页跳转专注区后，导航为“02 专注”，三个内容列均进入 visible / opacity=1，阅读进度值约 0.49；后续动态旅行预览可正常加载两张旅行卡片。
- 指针移动到旅行卡片后实际 CSS 变量为 x=-1.27px、y=-2.75px、zoom=1.04，处于约定范围内。
- 稳定滚动位置下切换文章分类，工具栏纵坐标由 388.925px 变为 388.700px，差异小于 1px；结果正确变为三篇。
- 旅行卡片与详情的共享过渡名称一致，进入后缩略底图可用、高清图 ready；本轮该旅行页错误日志为空。没有修改照片元数据或切片。
- 390px iframe 验证手机菜单可展开四个导航项，关闭后 inert=true、visibility=hidden；这是响应式浏览器验收，不代表真机触摸 / Safari 全覆盖。
- `?graphics=static#travel` 验证 motion=reduced、pending 节点为零、开场文字已 ready。系统级减少动态偏好的分支和 CSS 已覆盖代码检查，没有修改用户 OS 设置。

## 验证边界

没有对所有手机设备做帧率 / 耗电测量，不声称 FPS 提升。原生 View Transitions 的支持程度随浏览器而异。数据服务、上传、发布与地图 API 没有改动；不要把本轮交互验收当作新的上传或定位数据写入测试。
