# 宽幅主页与滚动分形背景

验证日期：2026-10-12。

## 设计调整

- 主页单独使用 `home.css`：主容器取消最大宽度，每边保留响应式安全留白；文章阅读、旅行详情与管理页的版心不变。
- 章节标题由侧栏改为通栏。当前工作双栏展开、历史工作两列、技术栈三列、文章双列索引、旅行宽幅照片；移动端回到单列。
- 青绿色与赭色分形采用有粗细层次的笔触和少量色面，构图向屏幕外延伸。正文使用纸色阅读底层，照片和茶壶有独立底层，避免黑色线条与文字混在一起。
- 两个相同的视口高图块同步播放，背景沿滚动方向移动，速度为正文的 28%。循环偏移取模，一个图块退出时另一个位于同一位置，长页面不会到达视差上限。
- 保留四种分形的 2000ms 生长、1000ms 停留、2000ms 消退。滚动只更新背景轨道，不重启动画；没有滚动劫持。
- 浏览器实测发现 SVG use 副本的路径动画显示不稳定，因此采用直接绘制的两个同步图块。减少了三角分形深度及龙曲线迭代，控制绘制复杂度。
- 大屏旅行照片加载已有 2560px 预览，手机使用已有 1000px 缩略图；不加载原片，不变更云端数据。
- 曾尝试浏览公开设计参考站，但访问未获准；没有绕过限制，也没有把未浏览的站点写成已验证案例。

## 浏览器实测

使用内置浏览器、本机静态生产构建和 `tests/fixtures/travel-ui-server.mjs`，没有管理接口写入。

- 1920×1080：主容器实测约 1905px，扣除侧留白后首屏内容 1751px，当前工作双栏约 727px / 799px；无横向溢出。
- 1280×720：检查首屏、工作、文章、旅行。彩色分形在留白与屏幕边缘可见，正文底层清楚，照片不被线条覆盖。
- 滚动联动：滚动位置 1043.20px 时背景偏移 -292.10px；向上滚动到 665.60px 时偏移 -186.37px，与 0.28 比例一致。
- 390px 与 320px 手机 iframe：实测文档宽度等于视口宽度；首屏、经历、旅行无横向溢出；菜单打开后保留原四项，旅行链接仍跳到主页第四章。
- 834px 平板 iframe：文档宽度 834px，无横向溢出；内容区约 768px，技术栈三列各约 255px；首屏保持双栏。
- 文章分类“渲染与光照”显示 3 篇；搜索不存在的词显示空状态；清除筛选恢复 21 篇。
- 桌面两张旅行封面加载完成，使用 `preview.jpg`，naturalWidth 均为 2560px。
- `?graphics=static`：可见静态枝状背景，`data-growth=static`、`data-parallax=off`。减少动态偏好与无 JS 回退由源码/自动测试覆盖；没有声称完成真机或系统级设置测试。
