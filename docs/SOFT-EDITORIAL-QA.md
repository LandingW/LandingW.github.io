# 柔和通透的主页与旅行 UI

日期：2026-10-13。

后续背景设计已由 [连续分形地形](FRACTAL-TERRAIN-QA.md) 替代；本文的前景材质与布局仍适用。

## 设计依据

- 实际浏览 [Cosmos](https://www.cosmos.so/)：借鉴其周边装饰、中央留白、圆润图片容器和低对比卡片边界。
- 实际浏览 [Linear](https://linear.app/)：借鉴清晰的主次层级、克制边框和微弱浮起感；不照搬其深色主题或产品界面。
- 保留本站暖纸色、衬线标题、朱红强调、茶壶与 Cornell Box，不引入另一套字体或图像素材。

## 改动

- 统一 `home-surface / home-radius / home-edge / home-shadow / home-blur` 设计变量。正文与卡片为 76% 不透明的暖色表面，背景轻微可见；文字本身没有降低透明度。
- 桌面磨砂 3px、手机 2px，不动画化模糊。浏览器不支持 backdrop-filter 时使用 94% 不透明底色；减少透明偏好使用实底。
- 卡片圆角按尺寸在 24–42px 之间变化，手机 26px，紧凑组件 18px。按钮、筛选、茶壶模式切换使用胶囊形态；不再靠大范围硬边框划分所有内容。
- 首屏文案与曲面展台使用相同的柔和表面，工作经历的当前角色保留双栏，技术细节使用轻色嵌入面板。专注与文章卡片有独立间距；章节标题移除整块矩形底板。
- 旅行列表、旅行标题、照片、国家轮廓、地图容器共用圆角节奏。地理底图仍不透明，高清查看器与私有编辑器没有修改。
- 手机分形沿两种不同周期的缓慢曲线游走，枝叶间隔、三角形尺寸和曲线控制段有确定性的变化。保留自相似细节与完整连接，不再等距排队。
- 桌面改成左右两条不同相位的连续分形，替代放大裁切和重复平铺。所有尺寸都只有一张按文档长度覆盖的 SVG，滚动不取模，继续保留 2s 生长 / 1s 保持 / 2s 消退。
- 更新画布长度不会改变已有坐标；静态、无 JavaScript 和减少动态回退保留。无新增依赖。

## 验证

- lint、97 项测试及 31 页静态生产构建通过；最后的 CSS 窄屏微调另行构建。
- 回归检查覆盖：全尺寸画布覆盖、两条桌面路径的连接与父子生长顺序、长页面坐标稳定、手机所有线段横向范围、共享材质变量、减少透明与无脚本回退。
- 本机生产版 1280×720、390×844、320×740 验收。正文实际为 `rgba(250,248,243,0.76)`，桌面 `blur(3px)`。320px 文档滚动宽度 305px、390px 为 375px，未横向溢出。
- 手机菜单打开、切换到文章、筛选「渲染与光照」实际返回 3 篇，跳转旅行列表与进入旅行详情成功。
- 旅行页面使用本机只读公开媒体代理验收。世界地图是实底、圆角 26px，旅行卡片是轻透底色；国家轮廓、地点章节、地图与设备信息仍存在。
- 手机旅行详情滚到底部：`scrollY=4440`、背景偏移 `-1243.2px`、画布底部视口坐标 `1758.4px`，完整覆盖 844px 高度。
- 本轮不修改、上传或删除照片，不改旅行数据，不部署 Worker；浏览器响应式验收不等于真机 Safari 或定量 GPU 帧率验证。
