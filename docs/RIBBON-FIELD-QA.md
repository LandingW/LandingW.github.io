# 柔光丝带与文字联动

日期：2026-10-13。按用户选择「柔光丝带：围绕标题流动，阅读和指针牵引形状」替代地形轮廓背景。保留公开页面现有排版、暖纸色、圆角卡片和图形学展品。

## 视觉参考与取舍

- 实际浏览 [React Bits / Silk](https://reactbits.dev/backgrounds/silk)：借鉴宽幅曲面、渐变高光和柔和边缘，不使用其代码、粒子噪声或紫黑配色。
- 实际浏览 [Lusion](https://lusion.co/)：借鉴稳定前景、留白和输入驱动图形的层次关系。
- 也查看了 Codrops 粒子案例和 MisterPrada 字体粒子。离散吸引子点云、连续吸引子细线原型不符合本次选择，均未发布；临时实现已移除。

## 实现

- 三条灰绿、蓝灰、沙金色带；宽度随曲线缓慢收展，横截面包含高光和羽化边缘。不再使用密集的黑色等高线。
- 四种相关构图 arc / drift / fold / unfurl。沿用 2 秒聚拢、1 秒保持、2 秒舒展的节奏，以连续几何过渡替代整片背景消失与重现。
- 使用 DOM Range 测量实际标题字符，合成一个阅读留白区域，影响附近色带弯曲；不是字形 SDF，也不改变真实文字的位置、透明度或可选中性。
- 当前阅读标题随滚动切换：首页首屏、经历、专注、文章、旅行、联系，以及旅行详情的标题与章节。标题目标、滚动、指针采用约 200ms 缓动。只有精细鼠标触发轻微局部牵引，触摸不被截获。
- 手机按竖屏纵轴直接生成曲线，不裁切横版图，也没有上下平铺接缝。背景覆盖整个视口；照片、地图和深色页脚保留独立实底。

## 针对持续闪烁的处理

- 用户确认停留时也会闪烁。检查旧版时正文入场已经 ready，正文 opacity=1、filter=none；没有证据表明首屏动画在反复启动。
- 旧版持续动画 SVG 轮廓叠加实时 backdrop-filter 是主要合成风险；没有在用户手机上录制复现，不能把这一判断写成已证明的唯一根因。
- 新背景为独立、不透明 Canvas2D。每帧先铺固定纸色，不清空到透明，不写入前景样式、不循环设置画布可见性。画布只在真实尺寸改变时重新分配。
- 公开首页与旅行卡片、导航移除实时 backdrop-filter，改用固定半透明暖白颜料。首屏重建限制到文字节点，不作用于整个按钮、导航、列表或卡片；THINK IN PIXELS 保留一次性字母点亮。
- 色带用一次生成的横截面纹理逐物理像素扫描线绘制，避免半透明多边形边缘重叠产生细条纹。无额外 WebGL 背景、依赖或运行时网络请求。
- 上限 30fps，手机 DPR ≤1.5，桌面 ≤1.75；后台标签页、照片查看器隐藏背景时暂停。卸载移除所有监听及观察器。减少动态与 `?graphics=static` 只绘制静态画面；无 JS 或 2D context 不可用时展示静态 SVG 回退。

- 110 项测试通过，ESLint 和 31 页生产构建通过。
- 新增数学测试：2/1/2 各阶段和完整循环的连续性、有限坐标、竖屏跨度/宽度、标题/滚动/指针的局部影响、渐变边缘和字母包围区域。

- 实际浏览器生产版：1280×720、390×844、320×740。检查首页、经历章节、旅行列表、挪威详情、页脚和静态模式；检查范围无横向溢出。鼠标输入产生 active 状态；滚动标题从 THINK IN PIXELS. 切到 Selected work. / Let’s talk.；详情动态标题正确更新为「挪威 峡湾&极光.」。
