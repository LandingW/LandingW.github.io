# 旅行页：颗粒回环

2026-10-14，采用所有者从四个背景小样中选择的「颗粒回环」。

## 范围

- `/travel/` 总览与 `?trip=…` 详情共用一层背景。首页仍是 Julia 墨色背景，管理页不加载背景。
- 不改变照片、相册清单、EXIF、R2、地图服务或上传处理流程。
- 世界地图、照片、标题、章节说明使用不透明底色；高清查看器打开时隐藏装饰背景。

## 生成与运行

- `src/lib/sand-raster.ts` 是构建前使用的纯算法模块，不导入浏览器组件。
- 保留小样的种子 `2887`、三组曲线、青绿／灰绿／陶土色及每组 76,000 个采样点。
- 点阵通过像素面积覆盖和 alpha 合成落到透明图像，不使用高斯模糊。
- 横版 1680 × 1400，315,400 字节；竖版 840 × 1960，325,166 字节。按设备方向只选择一张。
- 使用 `node --import tsx scripts/generate-sand-study.ts` 重建；两张 WebP 提交到仓库，常规页面构建不再计算粒子。
- 复用 `mountPrintMotion`：滚动事件合并为一帧，移动整张图，停止滚动后不继续运行 JS 循环。450ms CSS 过渡，最多移动 312px，无光标跟随或文本避让。
- `prefers-reduced-motion`、`?graphics=static`、无 JS 保留静态图片；后台暂停、卸载移除监听。

## 回归检查

`tests/sand-study.test.tsx` 检查确定性、独立竖屏构图、密度层次、透明留白、资源大小、页面隔离和不透底阅读区。现有 `print-study.test.tsx` 与 `ink-field.test.ts` 继续覆盖滚动边界、空闲停止、减弱动态效果与清理行为。

本机验收结果：

- ESLint 通过，122 项测试通过，31 个静态页面构建成功。
- 在既有 `tests/fixtures/travel-ui-server.mjs` 只读代理中加载公开的 3 次旅行、40 张照片；没有执行管理接口或云端写入。
- 桌面显示横版；390px / 320px 竖屏选择 `sand-portrait.webp`，总览与详情均无横向溢出。
- 从挪威地图图钉进入相册，返回全部旅行正常；章节文字纸面计算色为 `rgb(250, 248, 243)`、不透明度 1。
- 390px 手机照片章节滚动位置 1817.6px 时，背景位移约 -127.32px；接近页尾时图片仍完整覆盖屏幕，没有拼接或露边。
- 高清查看器可打开并切换 1:1，打开时背景 `display: none`，关闭后恢复。
- `?graphics=static` 滚动后仍为 `data-art-motion="paused"`、位移 0。首页默认图片与管理页隔离由 SSR 回归测试验证。

浏览器视口模拟用于检查响应式布局，不代表在实体手机上进行性能基准测试。
