# Julia 分形与文本边界

> 历史轮廓版本。用户随后选择「墨色渗化」，当前实现与验证见 [INK-FIELD-QA.md](INK-FIELD-QA.md)。以下记录不代表当前背景渲染方式。

日期：2026-10-14。用户明确选择“数学分形：Julia / Mandelbrot 的旋涡和自相似边界”，希望文本框与背景产生互动，并保留此前的慢速滚动、不跟随光标与性能约束。

## 数学与视觉

- 本次实现的是 Julia 集的逃逸场轮廓，不是 Mandelbrot 集，也不是用 fBm 等高线模拟分形。迭代为 `z ← z² + c`，`c = -0.8 + 0.156i`；在 801×801 网格上采样，最多迭代 160 次，再对 10 / 26 / 58 三个逃逸层级做 marching squares、几何简化和二次曲线重建。高层级边界是有限采样近似，不是任意放大精度的精确集合。
- 自行生成全部几何；不复制艺术家的图片或代码。用淡灰绿与赭色的色层表现旋涡的嵌套关系，保留暖白纸面。竖屏单独旋转、缩放和编排；不是横屏直接裁切。
- 正文卡片完全不透底，章节标题有局部纸面，避免数学细节穿过文字。

## 文本框如何互动

- 读取公开页面实际面板的坐标、尺寸与圆角，建立圆角矩形距离场。分形轮廓靠近边界时产生局部向外偏折，而不是给卡片加普通 hover 或鼠标视差。
- 边界影响带在桌面最多 84px、手机最多 45px，同时受面板较短边的 22% 限制；浅文本条不会在中线形成跳变。相邻面板的影响做归一化，避免叠加尖峰。
- 只有布局或内容改变时重新测量；滚动使用缓存的文档坐标。工作详情展开收起、动态旅行列表和尺寸改变由 ResizeObserver / MutationObserver 更新。观察范围不包含背景 SVG，避免自己触发自己。
- 保留缓慢纵向视差与 650ms 位移收束；无光标监听。边界调整是设计上的局部几何映射，不是流体模拟。

## 性能与降级

- 复数迭代只在生成脚本运行，浏览器不运行 Julia 逃逸循环。原始轮廓 4,509 个点；两个图层共五条合并路径，点数预算 6,500，最多考虑六个可见面板。
- 请求合并为单个待执行帧，几何/位置更新上限 30Hz；尾帧补齐最终位置后停止。无输入时只有非常缓慢的 CSS 图层运动，不存在持续 JavaScript 绘制循环。
- 不使用 Canvas、实时 shader、backdrop blur、逐字 Range 测量或循环透明度。SVG 需要在输入时重新栅格化，因此不能声称“只有 GPU 合成、完全没有重绘”，也没有测得用户真机 FPS。
- 几何 JSON gzip 20,223 字节，竖屏两个静态 SVG 合计 gzip 58,919 字节，横屏 61,871 字节。静态 SVG 通过 picture 选取匹配朝向；SSR 不内联大量几何。交互几何就绪后一次切换，前景不参与透明度切换。
- 后台取消待执行帧；减少动态效果和 `?graphics=static` 不启动轮廓互动，显示完整静态作品。无 JS 时仍显示静态 SVG。卸载移除监听和观察器。

- 109 项测试通过：复数轨道、采样层级、生成资产一致性、数量/压缩预算、独立竖屏取景、圆角边界局部性和连续性、浅面板无中线跳变、实际面板尺寸改变、滚动复用布局缓存、30Hz 上限/尾帧、静态/后台/卸载以及原有文章和旅行回归。
