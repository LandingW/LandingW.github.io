# 贯穿主页的分形背景

日期：2026-10-12。

> 手机构图已在 2026-10-13 改为[原生竖屏连续画布](FRACTAL-PORTRAIT-QA.md)。下文旋转横版 SVG 的描述仅为历史验收记录，不是当前实现。

## 改动

- 将唯一的 `GrowingFractal` 从 Hero 移到主页容器，覆盖整个视口；滚动至工作经历、技术栈、文章、旅行及联系区时仍使用同一个背景。
- 移除首屏右侧裁切和额外 0.28 透明度。背景整体强度 0.95，保留每根线的原始低透明度，并在中央轻微衰减，以维持文字可读性。
- 竖屏将 SVG 构图旋转 90°，避免 `slice` 裁掉两侧树枝；使用大视口高度，减少移动浏览器地址栏伸缩时的构图跳变。
- 深色页尾的底色放到分形层后方；照片及正常内容保持在分形前方，不增加另一份动画。
- 保留四种形态和 2s 生长、1s 停留、2s 消退的循环。继续支持静态模式、减少动态偏好、页面隐藏时暂停、无 JavaScript 回退。打印隐藏装饰。
- 不改正文、照片数据、导航顺序、茶壶或文字启动效果，无新增依赖。

## 验收

- 76 项测试通过；新增主页仅一个背景实例、背景位于 Hero 外部、全屏定位、禁止截获指针、竖屏构图及静态回退检查。
- lint、TypeScript 和生产构建通过。完整主页 SSR 测试会触发 Three.js 的 CJS 弃用警告，不影响构建或浏览器代码。
- 本机 3003 静态构建预览：工作经历区截图可见完整背景，定位 fixed，矩形 top=0、宽约1265px、高720px；不再随 Hero 离开视口。
- 旅行预览照片没有被分形覆盖；底部联系区域保留深色底色且可看到分形线条。
- 390px 手机容器：实际内容宽度和滚动宽度均375px；竖屏 SVG 旋转矩阵正确。导航可打开并跳至文章区，背景始终 top=0、状态 cycling；实际观察到 Koch 和 Dragon 形态继续切换，没有因离开首屏而暂停。
- `?graphics=static` 下保留完整枝状构图，不循环；不声称完成真机或定量帧率测试。
