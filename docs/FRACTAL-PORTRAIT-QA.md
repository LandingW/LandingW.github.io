# 竖屏连续分形背景验收

日期：2026-10-13。

## 实现

- 手机竖屏使用独立的 420 单位宽纵向构图，不再缩小或裁切横版图案。断点为宽度不超过 760px 且竖屏；横屏与桌面保留原构图。
- 手机只渲染一个沿文档延伸的 SVG。高度覆盖整个页面的滚动相机范围，并保留边缘余量；页面高度变化时重新计算覆盖长度。
- 分枝沿连续主干延伸；三角分形共享端点；Koch 与龙曲线各自连接为贯穿纵向的单一路径。生成器的段长只控制几何生成，不产生独立 DOM 图块。
- 移除手机图块上下渐隐与重复平铺。滚动偏移为 `-scrollY * 0.28`，不取模、不回绕。
- 保留四种形态、2s 生长 / 1s 保持 / 2s 消退、静态与减少动态偏好、页面隐藏暂停。长主路径使用短描线逐渐填满，使整页各处同时成形；递归枝叶仍逐层生长。
- 保留正文阅读底色，避免细线和文字混叠。不改照片、地点、后台或文章数据，无新增依赖。

## 已验证

- lint、94 项测试、31 个静态页面的生产构建通过。
- 新增测试验证四种生成器确定性、主路径只有一个起点、横向范围、纵向覆盖、父子生长顺序与两秒时长；覆盖 320 / 390 / 430px 和最长 25,000px 文档。
- 本机生产预览 390×844：只有一个 `.fractal-field`，没有 `.fractal-tile`；SVG 为 `0 0 420 4200`，实际高度 3752px，`mask-image: none`。
- 主页滚动 1350.4px 时背景偏移 -378.11px；滚至 8105.6px 时偏移 -2269.57px，画布底部仍在视口坐标 1482.43px，覆盖 844px 视口，没有回绕到开头。
- 320×740：文档宽 305px，不超出视口；底部背景仍覆盖至 1198.75px。浏览器滚动条占用部分宽度属于正常布局。
- 已目视检查分枝、Sierpinski、Koch、Dragon 的纵向图案，以及主页顶部、工作经历区、底部附近。跨屏滚动使用同一画布，无短图上下淡出拼接。
- 390px 旅行页同样使用单个连续画布。由于本机 3003 预览未能加载线上相册，本轮仅验证该页背景及布局，不将本机相册状态作为云端服务结论。
- 740×390 横屏及默认 1280×720 桌面均为 `landscape`、两个原有图块、零个竖屏画布。检查后恢复浏览器默认视口。
- 属于浏览器响应式尺寸验收，未声称真机 Safari 或定量 GPU 帧率测试。
