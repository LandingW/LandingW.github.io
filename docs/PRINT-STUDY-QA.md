此文为历史版本记录。2026-10-14 按用户选择替换为 [Julia 数学分形与文本边界交互](JULIA-FIELD-QA.md)。下面的矩形版画几何与“不更新路径”描述不再代表当前实现；缓慢滚动、不跟随光标和生命周期控制仍保留。

日期：2026-10-13。针对用户反馈的卡顿、希望参考数字艺术作品、不喜欢光标响应，替代柔光丝带实现。

## 实际参考

- [Vera Molnár / (Des)Ordres，Digital Art Museum](https://dam.org/museum/artists_ui/artists/molnar-vera/des-ordres/)：查看作品组图。借鉴规则几何中的有限微扰、嵌套与负空间，不复刻其方格网构图。
- [Matt DesLauriers / Sierra](https://sierra.mattdesl.com/)：查看印刷作品照片和色版说明。借鉴分层颜料、有限配色与纸本呈现，不采用其风景结构、作品图片或代码。
- [Anders Hoff / Sand Spline](https://inconvergent.net/generative/sand-spline/)：查看样条图像及生成方法说明。借鉴平滑曲线族的秩序，不采用密集粒子或黑色线云。

新图形为自行实现的圆角几何曲线族：超椭圆参数与小幅多频扰动，经闭合 Catmull–Rom 转为 Bézier 路径，采用灰绿、蓝灰、赭色三种印刷色层。桌面和竖屏分别编排位置、比例和线条数量。

## 性能问题与改法

- 旧实现每帧沿每一行物理像素绘制三条丝带。例如 844px 高、1.5 DPR 时，每帧 3,798 次 `drawImage`，30fps 上限对应每秒约 11.4 万次调用；滚动还会重新测量标题字符。此数字来自代码计算，不是用户手机的性能采样。
- 删除该 Canvas 渲染器、逐字 Range 测量、循环几何插值以及光标牵引。背景没有定时器、持续 rAF 循环、Canvas 绘制、路径/透明度更新、pointermove 监听或 DOM 尺寸轮询。
- 两个预生成 SVG 图层，只对外层做 CSS transform 动画。桌面共 48 条曲线、手机 40 条；每条 12 段 Bézier。两种尺寸均在 SSR 中提供，CSS 只显示当前朝向；装饰 SVG 的 gzip 体积设有 26KB 测试预算。
- 图层的自主运动周期为 56 / 73 秒，小幅平移与旋转；不追随鼠标、不依据文字位置变形。不能将这个改法称为实时分形生长或几何变形。
- 按用户后续反馈恢复纵向滚动视差：根据整页阅读进度，两层分别移动至最大 260px / 161.2px；按视口高度和短页面滚动范围收缩位移。没有分段重置、取模或折返，上下滚动可逆。
- passive 滚动事件只排一个待执行 rAF，读取 scrollY 并更新两层独立的 translate 属性；650ms CSS 过渡负责柔和收束。自主 transform 与滚动 translate 分离，曲线路径不变。只在 resize / ResizeObserver 内容尺寸变化时刷新滚动范围，滚动期间不测量布局；停止输入后不再请求动画帧。后台取消待执行帧，减少动态效果和静态模式关闭视差；卸载移除监听、观察器与内联位移。
- 移除全站卡片依赖光标坐标的视差处理；常规按钮反馈、主动拖动茶壶和照片/地图交互保留。
- 前景保持不透明文字和固定半透明纸面，无实时 backdrop-filter。没有全屏 opacity 闪烁。后台暂停、静态链接暂停、减少动态效果偏好下停止 CSS 动画；无 JS 也完整显示静态图形。
- 照片查看器打开时继续沿用隐藏背景的规则，不修改查看器或照片服务。

## 验证

- 106 项测试、ESLint 和 31 页生产构建通过。替换废弃丝带专用测试，保留其他内容、隐私、文章、地图和照片回归测试。
- 测试包含：几何确定性/有限性/闭合、线条数量预算、独立纵向构图、SSR 压缩体积、仅两个运动图层、关键帧只改 transform、无光标跟随、滚动位移连续且有界、100 次输入合并为一帧、滚动不测量布局、静止不重复写样式或持续调度、内容尺寸变化、生命周期暂停/恢复/清理、常规交互保留。
- 实际浏览器检查 1280×720、390×844、320×740；首页、经历章节、旅行列表、挪威详情可正常阅读，无横向溢出；竖屏仅显示两个 `0 0 420 900` SVG。
- 浏览器移动指针、点击导航、滚动和改尺寸后，所有装饰曲线路径字符串仍完全相同。背景 Canvas 数量为 0，运动图层为 2，CSS transform 矩阵随自主时间改变。
- 滚动视差追加验收：1280×720 首页向下滚动至 y=548.8 时两层收束到 -22.93px / -14.21px，接近底部 y=5442.4 时为 -211.38px / -131.06px；返回顶部均为 0，所有路径字符串保持不变。390×844 的经历章节 y=1088 时为 -32.15px / -19.93px，无横向溢出；同一锚点静态模式下两层位移均为 0、过渡时长 0s、动画 paused。
- 不声称测得用户真机帧率，不用功能测试或截图推导 FPS。这里验证的是明确消除高频主线程工作，以及实际交互/画面检查。
