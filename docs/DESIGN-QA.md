# 编辑式作品集版式 · 2026-10-12

## 参考与设计决策

本轮通过浏览器查看 [Kinfolk](https://www.kinfolk.com/) 和 [Pentagram](https://www.pentagram.com/)：前者的衬线字、主图与留白，后者的作品层级与图文关系，为版式提供方向。没有使用参考网站的照片、字体文件或源码。

整合本站现有内容，而非只增加动画：

- 首屏分为正文和独立茶壶研究区；主标题改为罗马体 / 斜体衬线组合，保留逐字闪烁与 GI 式文字还原；原全宽橙色带改为轻量当前工作信息。
- 基础配色改为暖白、墨绿灰与低饱和陶土红，字级和容器宽度通过同一组变量管理。使用本机字体栈，没有新增外部字体网络请求。
- 工作、技术栈、文章采用章节侧栏与主内容列；当前工作默认展开，其他工作可展开查看技术职责。所有职责文字、公司图标、技术标签均保留。
- 技术栈按方向组织为条目，文章区分最新导读与目录。首页第四区块保留简洁旅行预览，最多两次旅行，首图 / 次图使用不同尺寸。
- 旅行总览为地图侧栏与横向图文卡片，手记为文字说明加宽幅图片。地图、设备资料、高清分块加载、图片发布流程不变。

## 已验证

- 60 项测试、lint 和生产构建通过。新增测试验证正文 / 研究区分离、工作职责完整保留、只默认展开当前工作、章节内容区结构。
- 桌面首屏、工作经历、文章和旅行总览均经过浏览器截图检查。正文与章节侧栏分别处于独立的 Grid 列；工作详情按钮可展开，四项技术方向可读。
- 桌面文章内容列约 837px；旅行手记封面与其容器同宽，约 1124px。首页旅行预览收紧到约 608px 高，两个预览图高度约 367px / 265px。
- 390px 和 834px 的本机 iframe 模拟检查：内容宽分别为 375px / 819px（扣除滚动条），scrollWidth 与 clientWidth 相同，无横向溢出。这里是浏览器响应式检查，不是所有真机 / 所有字体平台验收。
- 验证技术职责展开、文章分类切换、旅行封面进入高清查看器和关闭返回。高清查看器仍显示 12 张照片与摄影参数；该旅行页浏览器错误日志为空。
- 保留菜单第四项旅行、已有免费地图及 Sommarøy 酒店附近坐标；没有修改 R2/D1、原片、切片、相机资料、文章存档或发布状态。
