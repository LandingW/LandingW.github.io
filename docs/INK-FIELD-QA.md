# 墨色渗化 / 2026-10-14

## 选定设计

用户从三张可切换小样选择第二版「墨色渗化」。本版保留该小样的 Julia 参数 `c = -0.4 + 0.6i`、灰绿色 `#5a6857`、连续密度与固定空间颗粒，不再使用大块填色的逃逸层轮廓。全屏构图在对侧加入较淡的小尺度印迹，横竖屏独立取景，没有垂直重复贴片。本文只描述网站背景，不修改文章、照片、旅行点位或云端配置。

## 实现与边界

- `ink-raster.ts` 只供生成脚本与测试使用；150 次上限的复数迭代不进入客户端运行时。
- `generate-ink-study.ts` 生成横屏 1680×1400、竖屏 840×1960 的透明 WebP。文件大小分别为 366232、299804 字节。浏览器的 picture 只选择当前方向，纹理上传复用已解码图片。
- 单个 WebGL pass、一次纹理采样、最多六个真实可见面板；圆角距离场提供局部位移与软阅读边缘。没有多 pass 模糊、逐帧随机噪声、光标输入或实时分形 shader。
- 标题、说明分别避让，不把完整章节标题栏变成横贯页面的白条。正文仍为不透底的 `#faf8f3`。
- 滚动使用缓存的文档坐标，不重新读取面板布局。ResizeObserver / MutationObserver 更新尺寸与新增、移除内容。
- 渲染上限 30 Hz；滚动后的有限尾帧负责缓慢收束，空闲后停止。移动端绘制比例不超过 1，桌面不超过 1.25，总像素预算约 150 万。
- 没有 JS、`?graphics=static`、减少动态效果、图形不可用或上下文丢失时保留静态图片。初始化成功后才显示动态画布；调整绘制缓冲尺寸时先恢复静态图，避免未绘制的黑帧。后台暂停，卸载释放资源与观察器。
- 此实现仍需要纹理采样和画布合成，不是零 GPU 开销。没有用户真机帧率测量，不承诺所有手机的固定 FPS。

## 验证

- 自动化覆盖：所选 Julia 参数、固定颗粒、连续透明度、独立横竖构图、文件大小、四区域覆盖、高清屏像素预算、六面板上限、有限收束、滚动无布局读取、纹理复用、布局更新、图形不可用、上下文丢失/恢复和清理。
- 现有滚动控制器测试保留 30 Hz 限速、尾帧、后台暂停、减少动态效果、静态模式和无光标输入，并增加有限自主尾帧测试。
- 本机生产构建浏览器检查：1280×720 首页和经历，390×844 经历、旅行列表、挪威详情；工作详情收起高度从约 888.8px 变为 565.8px，背景保持可用。
- 上述手机场景未发现横向溢出；动态图层成功就绪，竖屏绘制缓冲为 390×844。静态模式确认 motion 为 paused、动态画布隐藏、竖屏图片加载且显示。
- 本次本地验证：115 项测试通过、ESLint 无警告、31 页生产构建成功。线上部署结果以 GitHub Pages 发布记录为准。
