# 墨色渗化 / 2026-10-14

## 选定设计

用户从三张可切换小样选择第二版「墨色渗化」。本版保留该小样的 Julia 参数 `c = -0.4 + 0.6i`、灰绿色 `#5a6857`、连续密度与固定空间颗粒，不再使用大块填色的逃逸层轮廓。全屏构图在对侧加入较淡的小尺度印迹，横竖屏独立取景，没有垂直重复贴片。本文只描述网站背景，不修改文章、照片、旅行点位或云端配置。

## 实现与边界

- `ink-raster.ts` 只供生成脚本与测试使用；150 次上限的复数迭代不进入客户端运行时。
- `generate-ink-study.ts` 生成横屏 1680×1400、竖屏 840×1960 的透明 WebP。文件大小分别为 366232、299804 字节。浏览器的 picture 只选择当前方向，本次不修改两张图片。
- 按用户最新要求移除文字联动：不再测量阅读面板、避让文字、局部形变或使用面板遮罩；没有光标输入。正文仍为不透底的 `#faf8f3`，现有静态圆角与纸面样式不变。
- 当前背景只移动一个 picture，不含 Canvas / WebGL。原 `ink-scene.ts`、`ink-renderer.ts` 和 `ink-field.ts` 已删除；旧 Julia 轮廓实验仍不在页面中加载。
- 整张背景随滚动上下移动，位移为滚动进度乘以 `min(312px, 0.384 × 屏高, 0.09 × 可滚动距离)`，各类页长与屏高下均比上一版增加 20%。CSS 使用 450ms 平滑过渡，不循环闪烁或自行生长。
- 背景高度为视口的 140%，最大位移不超过视口的 38.4%，从页面顶部到底部都不会露出图片边缘。保留独立竖屏构图，不改成横向排列或纵向重复贴片。
- 滚动事件合并为单个待处理 rAF，只读取 scrollY 和缓存的整体文档尺寸；ResizeObserver 仅观察 body 尺寸。无面板测量、MutationObserver、背景重绘或空闲 JS 循环。
- 无 JS、`?graphics=static`、减少动态效果或 ResizeObserver 不可用时保持静态图片；后台停止更新，卸载清理观察器、事件与位移。减少动态效果同时关闭 CSS 过渡。
- 图片合成仍有浏览器开销，不等于零 GPU 开销。没有用户真机帧率测量，不承诺所有手机的固定 FPS。

## 验证

- 自动化覆盖：所选 Julia 参数、固定颗粒、连续透明度、独立横竖构图、文件大小、四区域覆盖、所有测试页长下 20% 位移增量、整个滚动范围不露底，以及当前组件不加载 Canvas / 文字联动逻辑。
- 保留滚动控制器的事件合并、后台暂停、减少动态效果、静态模式、无光标输入和卸载清理测试；可选历史场景的限速和有限尾帧测试仍在，当前背景不传入场景。
- 本机生产预览实测：1280×720 首页 / 经历段，390×844 经历段 / 旅行列表，背景均为 `julia-ink-scroll` 且没有 Canvas；桌面使用横屏图片，手机使用已加载的竖屏图片，未发现横向溢出。
- 桌面从首页滚动至经历段，图片目标位移从 0 变为约 -40.15px；手机继续向下滚动时从约 -30.34px 变为 -62.31px，图片仍覆盖视口。静态模式中 scrollY 从 1088 变为 1932，图片位移保持 0、motion 保持 paused。
- 旅行列表浏览器控制台未记录错误或警告。本次本地验证：114 项测试通过、ESLint 无警告、31 页生产构建成功。线上部署结果以对应提交的 GitHub Pages 发布记录为准。
