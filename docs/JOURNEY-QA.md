# 旅行地图册式详情页

日期：2026-10-12。只改网站前端；不修改旅行标题、说明、照片、GPS、设备数据、发布状态或云端配置。

## 设计依据与范围

- 延续当前暖白、墨绿与陶土红的视觉体系，将单次旅行分成「封面和国家轮廓 → 地点 → 影像 → 拍摄档案」。
- 本轮只读查看了 Aman（https://www.aman.com/）和 Black Tomato（https://www.blacktomato.com/）公开首页的 HTML 内容与章节结构，采用目的地导向、摄影优先和分层组织的思路。Black Tomato 的浏览器访问随后被拒绝，未再尝试访问；不声称完成参考站的视觉截图比对。未复制图片、字体、源码或品牌设计。
- 本地页面通过内置浏览器实际截图与交互验收。最初预览超时，恢复后使用本地 fixture；未绕过 Edge 或参考站的访问权限。
- 不改首页菜单顺序、首页第四项旅行预览、后台编辑流程与 Deep Zoom 查看器。

## 实现

- `TripStory`：非等宽照片／地理侧栏、坐标叠字、章节化版式、不等宽摄影编排；封面延续共享元素过渡和缩略图底图。
- `CountryOutline` / `country-geography`：Natural Earth 50m 国家轮廓，独立延迟加载。国家根据坐标匹配，缺失海岛仅使用目的地中明确的国家名称回退；未知仍显示未知。SVG 标题、数据署名、精确坐标与低分辨率示意说明齐全。
- `TripAtlas` / `TripPlacesMap`：旅行定位和照片 GPS 独立展示，同位置照片聚合；地图编号与列表双向联动、键盘 Enter／Space、文本安全 tooltip、点位照片高清查看、全部点位适屏、瓦片错误重试。坐标跨日期变更线时使用最小经度范围，极区仅限制地图投影、不改保存坐标。
- `TripEquipment`：机身、镜头与镜头规格分开，汇总实际焦距、光圈、快门和 ISO；缺少型号明确显示未记录。
- 动效：轮廓描边和填充、有限次数的点位波纹、章节指示、选点飞行、切换详情淡入、照片和光圈线稿的轻交互。沿用原滚动入场，尊重减少动态效果与 `graphics=static`，没有引入动效库。
- 地图接近视口才初始化，不批量预取瓦片，保留 OpenStreetMap 署名、浏览器缓存与服务说明。

## 自动验证

- `npm test`：新增 11 个测试，合计 71 项。
- 国家轮廓匹配、缺失海岛回退、不猜测未知国家、坐标零值、南／西半球、跨日期变更线、极区、其他相册隔离、同地照片聚合、无 GPS 不继承旅行定位、原数据不变、机型不猜测及章节语义覆盖。
- 原「无目的地不捏造」测试改为检查目的地字段本身，而非禁止加载提示出现“目的地”三个字；仍验证地点未知和设备未知。照片 figure 数量断言限定真实照片，不计入新增国家轮廓。

## 浏览器验收

运行 `npm run build` 后使用 `node tests/fixtures/travel-ui-server.mjs`，端口 3003，只读公开媒体，编辑接口仅存内存。

- 真实挪威旅行：轮廓、坐标、酒店附近详细地图及 1 个旅行定位；12 张照片均无 GPS，未制造照片点位。
- 地图瓦片实际载入；桌面日志未发现警告／错误。
- 手机 390px iframe：内容宽和滚动宽均 375px，无横向溢出；截图检查首屏、地图、点位列表。
- 平板 834px iframe：内容宽和滚动宽均 819px，无横向溢出；保留非等宽照片／国家侧栏。
- 桌面章节跳转：修复全站 scroll-padding 与章节 scroll-margin 相加后导致的活动指示滞后。设备章节顶端约 176px，导航底端约 150px，正确激活「03 拍摄档案」。
- 照片索引显示 12 张，点击第 2 张打开 7008×4672 高清查看器，关闭后恢复列表。
- `PHOTO_UI_DETAIL_FIXTURE=1`：仅内存注入明确标注的样例坐标，3 张照片形成 2 个拍摄点，加旅行定位共 3 个点位。验证列表点选高亮、键盘 Space 选择另一个点位、点位照片打开对应第 3 张高清图片。样例不进入云端或站点构建。
- 关闭点位照片后保留当前选点；返回总览清除详情章节 hash。已有未定位相册显示未知国家和无地图的空状态，没有生成默认坐标。
- 未声称完成真机触控、Safari 或定量帧率测试。

## 数据边界

当前挪威旅行仍叫「待整理 · e」，描述仍为用户已保存的待整理内容。保留这类内容，不为设计效果改写旅行事实。照片的具体机身／镜头型号目前缺失，镜头规格与曝光信息正常展示；可通过已有管理页补录。照片上传与数据更新仍不需要重新编译网站。
