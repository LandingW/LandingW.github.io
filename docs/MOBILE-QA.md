# 手机端布局与地图交互修正

日期：2026-10-12。范围为现有网站前端；照片、旅行文字、坐标、设备数据、上传和云端配置均不修改。

## 调整

- 手机详情首屏收紧间距，正文 13px、辅助信息 11–12px；国家卡使用整宽图文网格，移除小屏的纯装饰旁白。真实国家、坐标、数据署名保持完整。
- 窄屏／粗指针地图默认不接管拖动。点「操作地图」才开启手势，点击「完成操作」、按 Escape 或将地图滚出视口后恢复页面滚动。锁定时 Leaflet 子树 inert，外部操作按钮和 OSM 署名仍可访问。
- 手机多点位用带标签的原生 select（16px）切换，避免内外两层纵向滚动。单点不重复渲染选择列表；无点位不保留空侧栏。点位照片两列展示。
- 章节活动状态根据实际导航边界、scroll-padding 与 scroll-margin 判断，不再假设统一 210px。
- 竖向照片在手机手记中使用完整列宽；照片索引图注改为上下排列。机身、镜头和曝光信息增大字号，极窄屏设备信息单列。
- 高清查看器六个按钮采用等宽网格，手机至少 48px 高；长图注限制高度且可滚动，横屏收起重复底部说明，拍摄参数仍可从信息面板查看。
- viewport-fit=cover 配合页头、页面左右留边、章节吸顶和查看器的 safe-area；保留用户缩放，不设置 maximum-scale。

## 验证

- `npm test`：74/74 通过。新增地图五类手势开关、多点位 select 语义与完整选项、单点和空状态测试。
- `npm run lint`、`npm run build`（包含 TypeScript）通过。
- 本机只读 fixture 端口 3003；响应式 iframe 高度可选，外层不再滚动。浏览器 viewport override 与实际 DOM 宽度不一致，所以断点以 iframe 的实际 clientWidth 为准，非真机模拟。
- 320px 容器：页面 clientWidth/scrollWidth 均 305px（15px 桌面滚动条）；首页、旅行详情无横向溢出。查看器隐藏页面滚动条后宽 320px，六个按钮约 48×48px，照片区域约 501px 高；摄影参数面板可打开。
- 390px 容器：页面宽和滚动宽均 375px；首图从原约 422px 提前至约 377px。实际截图检查首屏、国家卡、地图、设备信息；国家辅助字号为 11px。
- 834px 容器：页面宽和滚动宽均 819px，保留双栏摄影／国家布局。
- 844×390 横屏容器：查看器宽度及滚动宽度均 844px，照片区域约 294px 高，底部控制条未超出高度。该项以 DOM 尺寸验证，浏览器截图视口曾裁切，不能视作完整横屏真机视觉验收。
- 手机地图开启后 inert 移除；Escape 退出后 inert 恢复。真实挪威旅行仍只有一处旅行定位，没有替无 GPS 照片捏造位置。
- `PHOTO_UI_DETAIL_FIXTURE=1`：只在内存加入三张样例照片的坐标，聚成两处拍摄点，连同旅行定位共三项。选择第三项后地图第三个标记高亮，打开对应第 3 张照片，关闭后 select 保留第三项。已恢复真实数据 fixture。
- 未定位 test 相册正常显示空状态，没有生成国家或假坐标。手机菜单第四项仍跳往首页旅行预览，旅行总览可访问。
- 桌面 1280px 地图不锁定、没有 inert；拍摄档案跳转结束后活动项正确，章节 top 约 176px，导航 bottom 约 151px；控制台无警告／错误。
- 本轮未做 iOS Safari、Android 真机触摸／双指手势、实际刘海安全区或定量帧率测试。
