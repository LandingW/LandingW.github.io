# 连续分形地形背景

日期：2026-10-13。本轮替代 `SOFT-EDITORIAL-QA.md` 中的双列枝条 / 几何分形背景；保留其前景卡片、材质和布局。

## 实际参考

- [Tyler Hobbs / Flow Fields](https://www.tylerxhobbs.com/words/flow-fields)：实际浏览文章与画面。参考长曲线的视觉引导、疏密、负空间与相邻线条形成色面的构图原则，不复制作品或代码。
- [Inigo Quilez / Domain Warping](https://iquilezles.org/articles/warp/)：实际浏览文章和 fBm 域扭曲图例。采用多尺度噪声扰动采样域的数学方法，重新实现噪声、参数、轮廓提取及绘制。

## 实现与边界

- 不再沿两条竖轴镜像排列树枝、三角或折线。整个画面来自同一个连续世界坐标函数，无重复单元、平铺、上下拼接或横向裁切的桌面图。
- 四种形态：冲积流纹、沙丘、群岛、褶皱。共享灰绿 / 沙色 / 蓝灰的低饱和配色，以粗细两级轮廓和极淡的闭合色面建立层次。
- 旋转的四层 fBm 提供分形细节；域扭曲与各形态的宏观方向共同控制构图。Marching Squares 使用共享边顶点连接轮廓，处理鞍点；路径简化后用二次曲线平滑。
- 手机使用独立的特征尺度与纵向坐标范围，轮廓线宽使用 `non-scaling-stroke`。所有尺寸只有一张根据文档高度延伸的 SVG；滚动相机仍为 `-scrollY * 0.28`，不取模。
- 每种形态保持 2 秒生长、1 秒保持、2 秒消退。按轮廓层级错开描绘起点，在同一时刻完成；隐藏页面暂停，卸载取消动画，减少动态与无脚本时提供静态图形。
- 不新增依赖、外部运行时请求、图片素材或 WebGL 背景。不改文章、照片、旅行数据、管理界面或 Worker。
- 静态检查入口：`?graphics=static&fractal=alluvial`（也可为 `dunes`、`islands`、`folds`）。正常访问不带参数，四种形态自动循环。

## 验证记录

- 全套 100 项测试、ESLint、31 页静态生产构建通过。
- 新增 / 更新的测试覆盖：四种形态确定性、多尺度细节、世界空间连续性、轮廓只闭合或终止于画布边缘、桌面每个横向区域及纵向区间均有图形、手机独立尺度、有限坐标、静态回退和单画布结构。
- 减少空网格分配后，本机 Node 生成四行的四种形态约为桌面 145ms、竖屏 94ms（一次抽样，不是手机性能或帧率承诺）。
- 真实浏览器生产版验收：1280×720、390×844、320×740；观察到生长、保持、消退及形态切换。完整生长时只有当前形态可见，其他三组隐藏。
- 320px 主页：文档与滚动宽度同为 305px。1280px 主页：同为 1265px。390px 旅行详情加载稳定后：同为 375px。

- 旅行页通过本机只读公开媒体代理检查，成功显示 3 次旅行、40 张照片和挪威详情；未进行任何云端数据写入。
